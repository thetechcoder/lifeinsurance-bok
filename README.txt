Life InsuranceBOK  (Life Insurance in Nigeria: body of knowledge, CIIN-aligned)

WHAT THIS IS
An installable, offline-first web app: 39 chapters, front matter, 3 appendices and 360 CIIN practice
questions with model answers. Light and dark modes (button at the top of the Contents page and in the reader).

HOW TO PUBLISH (must be served over HTTPS for install and offline to work)
1. Netlify Drop (app.netlify.com/drop): drag the LifeInsuranceBOK folder onto the page. 
   Or Cloudflare Pages / GitHub Pages: upload the contents of the LifeInsuranceBOK folder as the site root.
2. Open the link on a phone, wait for "Saved for offline use", then Add to Home Screen / Install.
3. After the first load the app works with no connection. Updates arrive on the next online visit.

NOTES
- Practice tab: mock exams (timed, by level) and glossary flashcards (914 terms).
- App PIN: set it from the Contents or Progress page (privacy lock, not encryption).
- Progress (chapters read, practice results, where you stopped) is saved on the device only.
  Reset it from the Contents page ("Reset progress").
- Do not open index.html by double-clicking: browsers block offline features on file:// addresses.
